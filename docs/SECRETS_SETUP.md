# API Secrets Configuration Guide

## Local Development ✓

1. **config.local.js** (git-ignored)
   - Contains your actual API keys for local development
   - Already added to `.gitignore` — will NOT be committed
   - Your keys are safe locally

2. **How it works:**
   - `app.js` imports from `config.local.js`
   - Just test locally and everything works
   - No additional setup needed

## Cloudflare Pages Auto-Deployment Setup

Since `config.local.js` is git-ignored, it won't exist on Cloudflare's build server. Use the build script instead:

### Step 1: Set Environment Variables in Cloudflare Pages
1. Go to your Pages project → **Settings** → **Environment variables**
2. Add these production secrets:
   - `DIGITRANSIT_URL` = `https://api.digitransit.fi/routing/v2/hsl/gtfs/v1`
   - `TRANSITOUS_URL` = `https://api.transitous.org/api/v5/plan`
   - `DT_API_KEY` = your actual API key
   - `NOMINATIM_REV` = `https://nominatim.openstreetmap.org/reverse?format=json&zoom=18&addressdetails=1`
   - `NOMINATIM_VB` = `24.0,60.8,25.8,59.8`

### Step 2: Configure Build Command in Cloudflare Pages
1. In **Settings** → **Builds & deployments** → **Build command**:
   ```
   node build-secrets.js
   ```
   This makes Cloudflare generate `config.js` from your environment variables before deploying.

2. Leave the build output directory as default (no changes needed)

### Step 3: Update app.js Import for Production
After your first Pages deployment, you'll have `config.js` generated on the server. Update `app.js` import:

**For local dev:** (no change needed)
```javascript
import { ... } from './config.local.js';
```

**For production:** (after Cloudflare generates config.js)
```javascript
import { ... } from './config.js';
```

Or use a dynamic loader to handle both cases.

## How It Works

| Environment | File | Git Tracked | Source |
|---|---|---|---|
| **Local** | `config.local.js` | ❌ No (.gitignore) | Manual (your keys) |
| **Cloudflare** | `config.js` | ❌ No (.gitignore) | Generated by `build-secrets.js` from env vars |

## Security Checklist

✅ API key never in git  
✅ URLs never in git  
✅ `config.local.js` in .gitignore  
✅ `config.js` (generated) in .gitignore  
✅ Cloudflare env vars are secure  
✅ Repo stays public without exposing secrets
