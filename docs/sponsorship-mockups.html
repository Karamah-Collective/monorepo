5. Promo Panel — "All Restaurant Promos"

A new Promos pill button sits next to the existing Prayer Times pill. Tapping it opens a panel listing all sponsored restaurants that have promo codes. Tapping a code copies it. Each code is unique per IP to prevent abuse.

Anti-abuse: unique codes per IP. When a user taps a promo code (either in the popup or the promo panel), the server generates a unique code variant tied to their IP hash. This prevents one person from sharing the same code publicly. The restaurant can verify codes against a simple lookup. Users see their personal code; if they clear cookies/use a new device, the same IP hash generates the same code again.

7. Toast Notifications

The promo toast is persistent (not auto-closed) — it stays until the user taps the ✕ button. This gives them time to note the code.

Code HANAMI10-X7K copied!
Show this at Hanami Sushi for 10% off
Some restaurants support Halal Finder through sponsorship
Tap ℹ️ on any sponsor badge to learn more
Note: The promo code includes a short unique suffix (e.g., -X7K) derived from the user's IP hash. This makes each code unique while keeping it short enough to say at a counter.
