1. Overview

Manarah is a free, community-driven Progressive Web App (PWA) that helps users locate halal-certified restaurants, shops, mosques, and prayer rooms across Finland. As the platform grows, we are introducing a transparent, ethical sponsorship program that allows local businesses to gain visibility while directly supporting the app's mission.

This document outlines the sponsorship model: what sponsors get, how it's implemented, and how transparency is maintained.

2. Guiding Principles

  1. Transparency first. Every sponsored element in the app is clearly labelled. Users always know when content is sponsored.
  2. Halal verification is independent. Sponsorship has no influence on halal status tags, ratings, or user-reported data.
  3. Boycott overrides sponsorship. If a place is flagged on the boycott list, all sponsorship UI is suppressed — no exceptions.
  4. Community trust is non-negotiable. Users can tap an ?? icon on any sponsor badge to read the full sponsorship policy.

3. Sponsorship Tiers

We offer three tiers, each building on the previous one. All tiers display the same "Sponsored ?" label to users — the tier determines which features are enabled behind the scenes.

4.3 Promo Code Button (Featured & Spotlight)

An icon-only button (tag icon) appears in the popup action bar alongside Directions, Share, and Edit. It uses a subtle gold tint so it's noticeable without being intrusive.

Tapping it:

  1. Generates a unique promo code tied to the user's IP hash (e.g., HANAMI10-X7K)
  2. Copies it to the clipboard
  3. Shows a persistent toast (does not auto-close) with the code, offer description, and a dismiss ? button
Anti-abuse: Codes include a short unique suffix derived from the user's IP hash — unique per user, but short enough to say at a counter. Same IP always generates the same code.

5.2 How It Works

  1. Admin fills in sponsor_tier for the sponsored place(s)
  2. Optionally fills in promo code and promo text
  3. App picks up the change on next data refresh (~1 hour, or instantly with cache purge)
  4. All sponsor UI renders automatically based on the tier value
  5. To remove sponsorship, clear the sponsor_tier cell
No code changes are needed to add or remove sponsors. It's fully data-driven.

5.3 Boycott Override

If the boycott column is set to "yes", all sponsor UI is suppressed — enforced in code, cannot be bypassed from the sheet.

7. User Experience Walkthrough

A user finds a sponsored restaurant on the map:

  1. They see the pin has a soft breathing gold glow — subtle but distinct
  2. They tap it. The popup shows "Restaurant" badge, then a gold "Sponsored ?" badge with an ?? icon
  3. Below the title: restaurant name, address, and tags — unchanged from non-sponsored places
  4. In the action bar, there's a tag icon button with a gold tint
  5. They tap it ? unique code HANAMI10-X7K is generated and copied ? persistent toast appears
  6. They visit the restaurant and mention the code

A user searches for "sushi":

  1. Results show 4 matches. The 1st is sponsored — shows "Sponsored · Hanami Sushi"
  2. The remaining 3 are organic, ranked by relevance and distance
  3. The user can see at a glance which result is sponsored

A user taps the Promos pill:

  1. They tap "Promos" (next to Prayer Times) at the bottom-right
  2. A panel lists all restaurants with active promotions — name, offer, tappable code
  3. They tap a code ? it's copied ? persistent toast confirms

A user opens the places list:

  1. A carousel titled "Sponsored Restaurants" shows Spotlight partners at the top
  2. Below, the normal list shows all places. Sponsored ones have a gold chip
  3. Sorting, filtering, and favourites work identically
