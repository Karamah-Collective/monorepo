# Shared assets

Common files used by more than one surface live here instead of the repository root.

- `brand/karamah-logo.svg` is the canonical Karamah wordmark used by Website, Links, and Admin builds.
- `design/logo-animation-options.html` is the logo animation study page used to compare loader directions.
- `firebase-verify.mjs` is shared runtime support for admin-facing Firebase checks.
